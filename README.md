# Smart Task Manager CLI

Smart Task Manager CLI adalah aplikasi manajemen tugas berbasis Command Line Interface (CLI) yang dibuat menggunakan Python.

Project ini dibuat sebagai bagian dari proses pembelajaran Python dan pengembangan portfolio, dengan fokus pada penerapan konsep dasar pemrograman, CRUD, file handling, JSON, dan error handling.

## Features

- Menambahkan task baru
- Menampilkan daftar task
- Mengubah status task
- Menghapus task
- Validasi duplicate task
- Penyimpanan data menggunakan JSON
- Validasi input dan error handling

- GitHub
